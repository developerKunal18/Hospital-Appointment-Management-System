Features
- Register, search, and update patient records
- Add and manage doctors
- Organize doctors by specialization
- Book appointments with date and time
- Prevent overlapping appointments for the same doctor
- Track appointment statuses
- Cancel appointments
- Record payments and generate receipt IDs
- View patient appointment history
- Generate daily appointment reports
- Generate revenue reports
- Store data in JSON files

Tech stack
- Python
- JSON
- Datetime
- UUID
- OS
